После просьбы пользователя «можно не проверять» новые проверки прекращены. APK по просьбе пользователя не собирался и не устанавливался. Итоговая версия на телефоне/эмуляторе не проверялась. Gradle Sync через интерфейс Android Studio не запускался; проверялась конфигурация Gradle из текущего проекта.

## Ограничения

Уведомления WorkManager могут задерживаться системой. Импорт относится к регулярным двум неделям. Для проверки живого импорта новой группы и свайпов понадобится будущий запуск приложения. Настройка недели требует первоначального выбора 1/2. Существующие пользовательские данные на подключённом телефоне не изменялись.
