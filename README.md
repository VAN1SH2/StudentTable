## Расписание

Главный экран показывает выбранную дату текущей или следующей календарной недели. При первом открытии дня выбирается сегодня; ручной выбор сохраняется в течение этого календарного дня. После смены даты выбор возвращается на сегодня. Дни переключаются нажатием или свайпом. Время, календарь и номер недели определяются по устройству, без фиксированного часового пояса. Пара в 14:10 относится к 14:10 на телефоне. Во время пары отображаются минуты до её конца; счётчик обновляется автоматически. При изменении времени или часового пояса напоминания пересчитываются.

Перед ближайшей сегодняшней парой статус появляется только за 60 минут или меньше: «Пара начнётся через 60 минут», «Пара начнётся через 42 минуты», «Пара начнётся через 1 минуту». Доли минуты округляются вверх; раньше последнего часа надпись скрыта. После начала показывается время до конца пары.

Компактная шапка показывает активную группу, неделю выбранной даты и последнее успешное обновление. Кнопка ↻ обновляет расписание. Название группы открывает «Мои группы».

Карточки занятий используют компактные отступы: время, название предмета, тип и описание рядом, затем преподаватель и аудитория в одной строке. Корпус и кабинет выделены фиолетовым полужирным текстом 15 sp. Карточки имеют светло-серый фон на белом фоне экрана, без обводки и свечения. На узком экране длинные подписи переносятся на следующую строку. Этот вид используется на главном экране и в полном расписании обоих вузов; задачи остаются ниже информации о паре.

В карточках пар показываются невыполненные задачи того же предмета и группы. Если при создании выбрана конкретная пара, сохраняются её ID и календарная дата: на главном экране задача видна только в этом занятии, а не одновременно у лекции и практики. На недатированном экране двух недель учитывается ID пары. Общие задачи без привязки к паре по-прежнему показываются у всего предмета. Связь с предметом использует subjectId; старые задачи без subjectId связываются по названию. Просроченные задачи выделяются красным только в своём блоке. Задачи без предмета видны на экране задач. Для ЭИОС ссылка открывается через Android Intent кнопкой «Открыть курс».

Нажатие на карточку пары открывает обычный редактор новой задачи с заполненными группой и предметом. В блоке «К какой паре» показывается прокручиваемый список карточек будущих занятий этого предмета на один календарный месяц вперёд. На карточке указаны день недели, дата, время и тип занятия. При открытии из карточки практики выбирается ближайшее будущее занятие именно этой карточки, даже если раньше есть лекция по тому же предмету. Выбранная карточка выделяется фиолетовым, дедлайн устанавливается на её начало. Дату и время можно изменить вручную: выбранная пара при этом сохраняется независимо от дедлайна. «Без привязки к паре» оставляет общую задачу по предмету. Создание работает и на экране полного расписания.

Для задач, сохранённых до 0.4.1, нужно один раз открыть редактор, выбрать нужную практику или лекцию и сохранить. Раньше приложение сохраняло только предмет и срок; восстановить выбранную пару однозначно нельзя. Миграция сохраняет старые задачи без догадок о привязке.

Список строится локально из двухнедельного цикла: учитываются опорная дата, номер недели выбранной группы и её подгруппа ИРНИТУ. Интернет не нужен. Занятия, которые уже начались, не включаются; окно ограничено календарным месяцем, а не четырьмя неделями. При создании задачи со страницы «Задачи» список появляется после выбора предмета. При редактировании существующей задачи её срок сохраняется до ручного изменения. Нажатие на задание внутри карточки пары открывает редактирование этого задания.

Внизу главного экрана есть «Посмотреть расписание на 2 недели». Это отдельный экран со сменой недели 1/2 и вертикальным списком дней.

## Группы и импорт

В «Мои группы» → «+ Добавить группу» выберите СФУ или ИРНИТУ, введите название и выберите результат. Можно сохранять группы обоих вузов. ID разных источников не пересекаются; задания относятся к выбранной локальной группе.

ИРНИТУ: поиск на официальном сайте через POST `https://www.istu.edu/raspisanie/poisk`, поле `zapros`, например `ИСТб-25`. Расписание выбранной группы загружается GET `https://www.istu.edu/raspisanie/grup/{id}/`. HTML-парсер читает чётные, нечётные и общие занятия. Неделя 1 — нечётная, неделя 2 — чётная. Первая опорная дата и чётность берутся из информации страницы; далее работает автоматическое чередование. При ручной коррекции меняется цикл групп только выбранного вуза. Время окончания при отсутствии на странице определяется по стандартной длительности пары ИРНИТУ 90 минут.

### Подгруппы ИРНИТУ

После загрузки расписания откройте «Мои группы» или настройки и выберите подгруппу под нужной сохранённой группой ИРНИТУ. Отдельный переключатель подгруппы убран из шапки главного экрана; выбранный номер виден рядом с названием группы. Номера берутся из занятий обеих недель; если сайт не обозначает подгруппы, приложение сообщает об этом. По умолчанию видны все подгруппы.

Выбор хранится отдельно для каждой группы. Показываются занятия выбранной подгруппы и общие пары без пометки подгруппы. Фильтр действует на главный экран, полное расписание, ближайшую пару, отсчёт до конца пары и список предметов при создании задачи. Напоминания о парах основной группы учитывают её выбранную подгруппу; при изменении выбора они пересоздаются. Задачи и напоминания об их дедлайнах сохраняются.

Все занятия остаются в Room, поэтому менять подгруппу можно без интернета. Обновление расписания сохраняет выбор. Старые пометки «Подгруппа 1/2» из версии 0.3.0 переносятся в отдельное поле при миграции, без обязательного импорта. В общей карточке нескольких групп парсер читает пометку именно выбранной группы.

Источники изолированы в `network/SfuScheduleSource.kt`, `network/IrnituScheduleSource.kt` и `core/IrnituTimetableParser.kt`. `UniversityScheduleSource` выбирает источник по вузу сохранённой группы.

### СФУ

Поиск СФУ выполняется через новый сайт: `https://sfu.ru/ru/education/schedule?search=<query>`. Ввод от двух символов, задержка 350 мс; устаревший поиск отменяется. Из Next.js/RSC извлекаются groupId, groupName, course, educationLevel и isSession. Выбранные ID и имя сохраняются в Room.

Для группы выполняется GET `https://sfu.ru/ru/education/schedule/{groupId}?date=&view=two_weeks&scope=regular`. Фиксированного `_rsc` нет. Расписание хранится отдельно для каждой группы; обновление транзакционно заменяет только её пары и timestamp. При ошибке старые данные остаются.

В поисковом ответе СФУ от 30.09.2026 у КИ25-20Б (2 подгруппа) указан ID 108257; прежний 107691 больше не найден на странице расписания. Если сохранённый ID перестаёт работать, источник ищет точное совпадение имени той же подгруппы и сохраняет новый ID. Это не постоянный поиск перед каждым обновлением. Дубликаты ID запрещены.

Активная группа задаёт отображаемое расписание. Основная группа задаёт напоминания перед парами. Удаление группы удаляет её пары, но сохраняет задачи без привязки к группе.

## Недели, задачи и уведомления

В настройках один раз выбирается текущая неделя выбранного вуза; ИРНИТУ также определяет её при первом импорте. Сохраняется понедельник текущей календарной недели и номер 1/2. Далее номер чередуется каждый понедельник автоматически. Вручную изменить нумерацию можно там же.

Редактор задачи позволяет выбрать группу и предмет из локального расписания, а также «Без предмета». Список поддерживает выполненные/невыполненные задачи, просрочку, все группы, редактирование и свайп влево. После удаления Snackbar «Задание удалено» предлагает «Отменить». Удаление отменяет запланированную работу; отмена удаления восстанавливает запись с тем же ID и пересоздаёт напоминание.

Напоминание перед парой: выключено / за 15 / 30 / 60 минут. После импорта и изменений настройки пересоздаются фоновые работы. WorkManager сохраняет работы после закрытия процесса и перезагрузки; Android может задерживать их при энергосбережении. Это приблизительные напоминания. Разовые переносы, каникулы и экзамены автоматически не учитываются.

## Файлы и миграция

- `core/.../Schedule.kt`: модели, контракт источника и календарь недель.
- `core/.../NextResponse.kt`, `NextTimetableParser.kt`: изолированный разбор Next.js/RSC, поиск групп, timetables и timetablePeriods.
- `app/.../network/SfuScheduleSource.kt`: HTTP и разрешение изменившегося ID.
- `core/.../LessonSubgroups.kt`: номера подгрупп и правила фильтрации общих занятий.
- `app/.../data/StudentDatabase.kt`, `data/database/DatabaseMigrations.kt`: Room 7, группы и миграции 1 → 2 → 3 → 4 → 5 → 6 → 7.
- `app/.../data/StudentRepository.kt`: локальные операции и транзакционный импорт.
- `app/.../ui/StudentViewModel.kt`: состояние, поиск, события и действия.
- `app/.../ui/StudentShell.kt`, `ui/screens/`, `ui/components/`, `ui/theme/`: навигация, отдельные экраны и светлая бело-фиолетовая тема.
- `app/.../reminders/Reminders.kt`: уведомления основной группы и дедлайны задач.

Миграция 2 → 3 добавляет вуз и цикл недель в таблицу групп, сохраняя все пары и задания. Миграции не используют destructive fallback: старые задачи, пары, даты дедлайнов, настройки недели и время обновления переносятся. Старые записи относятся к прежней группе 107691; при успешном разрешении её нового ID ссылки задач и пар обновляются.

Миграция 3 → 4 добавляет nullable-поля `groups.selectedSubgroup` и `lessons.data_subgroup`, переносит старые пометки ИРНИТУ. Таблица задач не меняется; выбор подгруппы изначально «Все». Новую схему Room экспортирует при следующей компиляции.

Миграция 4 → 5 добавляет nullable-поля `tasks.lessonId` и `tasks.lessonDate`. Существующие ID задач, сроки, напоминания, группы и настройки сохраняются. Дата пары хранится отдельно от `dueAt`. Внешнего ключа на пары нет: обновление локального расписания не удаляет задачи и их привязки. Если сайт изменит ID занятия, задачу можно перепривязать в редакторе; сама задача остаётся на экране задач.

## Проверки и запуск
